Rewindom 给编码 Agent 用的多租户 SaaS 底座

每做一个 SaaS，认证、租户、配额、权限、计费、官网 CMS 这一层都要重写一遍。写一次，后面的业务当模块挂上去，按租户开关——没开通就不挂路由、不进侧栏、不产生数据。它同时是 Agent-first 的：人和 Cursor / Claude 走同一条 Spec → gen → check 闭环，Spec 留空 Agent 必须追问、禁止瞎猜，机器闸门拦住越权和漏装配。不是脚手架喷发器，也不是低代码——模块就是 TypeScript 包，契约和测试都是代码。
