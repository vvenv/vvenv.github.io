Alice 听写

英文单词听写 App

孩子每天要听写单词，得有人一个一个念，念错了从头再来。于是做了这个：拍张照就能识出词表，自动朗读、可调语速与间隔、标错的词自动进错词本。手机放桌上写字时屏幕常亮，切后台、来电、拔耳机都会自动暂停，不会白读几个词。内置中考 1600、高考 3500 和人教、外研、闽教版的单元词表。

汤姆猫跑酷

原生 Android 3D 像素跑酷

给儿子做的。市面上的跑酷不是塞广告就是逼内购，所以这个免费、无广告、无内购，进度只存在手机里。三条跑道，穿过传送门会掉进另一个宇宙，水下更漂、天空跳更高、星空几乎没重力。路上会稀有地刷出 88 件中国文物，甲骨文、越王勾践剑、曾侯乙编钟——知识只在孩子自己捡到之后才出现，不弹题、不考问。画面做过护眼调色。

Rewindom

给编码 Agent 用的多租户 SaaS 底座

每做一个 SaaS，认证、租户、配额、权限、计费、官网 CMS 这一层都要重写一遍。写一次，后面的业务当模块挂上去，按租户开关——没开通就不挂路由、不进侧栏、不产生数据。它同时是 Agent-first 的：人和 Cursor、Claude 走同一条 Spec → gen → check 闭环，Spec 留空 Agent 必须追问、禁止瞎猜，机器闸门拦住越权和漏装配。不是脚手架喷发器，也不是低代码——模块就是 TypeScript 包，契约和测试都是代码。
